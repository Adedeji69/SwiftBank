# SwiftBank

SwiftBank is a responsive banking web application built with **HTML5, CSS3, Bootstrap, JavaScript, and Firebase**. The project is designed to simulate a modern digital banking experience with a clean interface, responsive layouts, and user authentication.

## Features

* User registration and sign-in
* Firebase authentication
* Responsive banking dashboard
* Account overview
* Transaction history
* Card management
* Profile and account settings
* Responsive mobile layouts
* Interactive UI components
* Form handling and validation
* Modern banking interface

## In Development

The following features are currently being developed:

* Money transfer functionality
* Receive money functionality
* Profile image upload
* Additional banking interactions

## Technologies

* **HTML5** — Page structure and semantic markup
* **CSS3** — Custom styling and responsive layouts
* **Bootstrap** — Responsive UI components and layouts
* **JavaScript** — Application logic and interactive functionality
* **Firebase** — User authentication and account sign-in/sign-up

## Authentication

SwiftBank uses **Firebase Authentication** to handle user registration and sign-in.

Users can create an account and securely authenticate before accessing the banking dashboard.

## Responsive Design

SwiftBank is designed to provide a consistent experience across:

* Desktop
* Tablet
* Mobile

The interface includes responsive layouts specifically designed for smaller screens.
